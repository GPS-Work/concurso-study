Ofertas BEP-RAM

Ativar a atualização no GitHub

  1. Coloca o conteúdo da pasta da aplicação na raiz do repositório, incluindo scripts e .github/workflows/bep-ram.yml. Mantém o ficheiro dentro dessas pastas. Se o upload não incluir a pasta oculta, usa Add file → Create new file e escreve esse caminho completo, copiando o conteúdo do ficheiro.
  2. Em Settings → Pages → Build and deployment → Source, escolhe GitHub Actions. Esta versão publica a aplicação e o ficheiro de ofertas pelo mesmo processo.
  3. Em Actions, abre Atualizar ofertas BEP-RAM e executa Run workflow no ramo principal do repositório. Se Actions estiver desativado, ativa-o. Se uma regra do repositório impedir a gravação pelo processo, a execução mostrará o motivo; a atualização não deve ser considerada ativa enquanto existir falha.
  4. Espera pela conclusão da publicação. Abre a aplicação e usa Atualizar painel. Confirma que aparece a data da consulta à BEP-RAM.
  5. Em Definições → Alertas BEP-RAM, escolhe RH e ofertas por verificar ou todas as ofertas sem vínculo. Ativa os avisos e autoriza a notificação do dispositivo quando disponível.

O processo está configurado para consultar a fonte de três em três horas. O GitHub pode atrasar uma execução e suspender horários em repositórios inativos. A data apresentada é a da consulta à fonte, não a da abertura da aplicação. Uma falha mantém a informação anterior identificada como tal.

As ofertas existentes no momento da ativação formam a base inicial. As seguintes podem gerar aviso ao abrir ou voltar à aplicação. A PWA não recebe notificações push com a app fechada neste modelo sem servidor de notificações.

Verificar o comportamento

  1. Abre Hoje: devem aparecer o número de ofertas gerais, as identificadas como RH, as que não foi possível classificar e a data da consulta.
  2. Abre uma oferta: deve abrir o detalhe oficial da BEP-RAM. Confirma os requisitos do aviso antes de candidatar.
  3. Desliga a internet e reabre: deve manter a última informação guardada, com a respetiva data. Depois de 24 horas, indica que pode estar desatualizada. Não deve afirmar que não há ofertas quando nunca conseguiu consultar a fonte.
  4. No iPhone, configura a automação de Atalhos descrita nas Definições para consultar o mesmo ficheiro de ofertas e mostrar avisos com a app fechada. Sem guardar IDs entre execuções, lembra ofertas abertas; não distingue apenas as novas.

O filtro procura RH na área funcional e na descrição das funções. Não usa contactos, locais de entrega de candidaturas nem nomes de pastas de documentos para classificar uma oferta como RH. Admissão sem vínculo não dispensa os restantes requisitos de cada concurso.
